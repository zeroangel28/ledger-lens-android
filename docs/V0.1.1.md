# v0.1.1 recovery changes

- Fix Ethereum balance RPC host; retain native balances when token indexing fails.
- Add BTC Esplora provider fallback; account paths and public-key import remain unchanged.
- Add encrypted TronGrid API-key configuration and recovery guidance. Reuse account-response TRC-20 balances, correct the mainnet USDT contract identity, and retain native/known-token balances when metadata queries fail.
- Honor HTTP 429 Retry-After and maintain a host cooldown; retry brief transient failures within a bounded budget. Do not keep polling during a long cooldown.
- Request only necessary Binance Spot exchange metadata and ticker pairs. Fetch quotes independently of address discovery, retain other successful quotes if one pair fails, and distinguish missing markets from network failures.
- Reproduced the pricing failure: Binance's unfiltered exchange catalog now exceeds the old 10 MB response cap. Scoped metadata responses are about 2.2 KB and all four requested native Spot pairs passed live checks on both Binance hosts.
- Show unit prices on asset rows. Unknown balances or quotes show an em dash/unknown label. Zero filters keep unavailable data visible. Partial discovery retains previously indexed tokens instead of silently setting them to zero.
- Cardano holdings: one synchronization attempt per account every 24 hours, including failed/cancelled attempts. The attempt timestamp is persisted before the first call, survives app restarts, and is migrated from existing balance timestamps. Manual portfolio refresh honors the same cap. Prices continue updating. A synchronization may need multiple address/token HTTP calls; no background job or forced retry is provided.
- Cardano uses the existing Blockfrost key when set, with an optional public Koios path for accounts without a key. Ownership validation remains local.

Install the new debug APK as an update over the previous APK to retain encrypted accounts and cache. Provider availability and physical Flex compatibility still require phone/device verification. This change never adds signing or private-key export.
