# 背景價格通知與 Cardano 更新

v0.4.1，2026-10-23。

## 背景通知要確認的設定

1. 在 Ledger Lens「設定」啟用「啟用漲跌通知」與「背景檢查」，並允許系統通知。
2. 點「開啟 App 電池／背景設定」，在手機提供的選項中允許背景活動／將電池使用設為「無限制」。也可用「開啟系統電池最佳化設定」查看此 App 的最佳化設定。App 不會自動改動系統設定。
3. Samsung 另到「設定 → 電池／裝置維護 → 背景使用限制」，將 Ledger Lens 移出休眠、深度休眠，加入永不休眠清單。系統版本的名稱與入口可能不同。通知允許與背景活動允許是不同設定。[Samsung 官方說明](https://developer.samsung.com/mobile/app-management.html)。

正常價格檢查約每 15 分鐘執行，開啟 App 時約每 30 秒。離開 App 另安排至少 30 秒後的一次背景檢查；不是每次都重設 15 分鐘週期。排程從 Application 初始化，Worker 可自行載入本機持倉，不需要 Activity 或 ViewModel 存在。

Android Doze、網路限制、省電與強制停止仍可能延遲／停止背景工作，無法保證精準到點。強制停止後需要再次開啟 App 才能恢復；不用強制停止來測背景通知。本版未加入持續前景服務或精準鬧鐘。[Android 背景限制](https://developer.android.com/training/monitoring-device-state/doze-standby)。

## 不必等行情的背景測試

1. 按「安排背景測試通知」，確認提示後回到手機主畫面，讓 App 在背景。
2. 至少一分鐘後查看通知匣；省電或休眠可能延後。通知標題會明確標示為「測試通知」。不要停在 App 畫面等它；若執行時仍在前景，測試會記錄原因而不冒充背景成功。
3. 回到設定查看「最近背景測試通知送出時間」。若時間沒更新或直到打開 App 才收到，確認前述系統設定。這個測試不查 Binance、不查鏈上餘額，不代表行情達門檻，也不計為有效價格檢查。

## 如何判斷真正的背景價格檢查

畫面分別顯示「最近背景嘗試」、「最近背景有效檢查」和背景結果。前景每 30 秒的刷新不會改寫這些背景紀錄。

- 沒有背景嘗試：先看排程是否已登記，再查省電、網路與 Samsung 睡眠清單。
- 有嘗試但沒有有效檢查：結果會指出沒有可監控持倉、報價／一小時參考價不可用、通知被封鎖、工作中止或其他錯誤。
- 有有效檢查但沒有通知：價格未必達到 ±3%／±5%，也可能仍在相同方向的一小時冷卻或尚未重新跨過門檻。

背景通知仍只使用本機已知的正餘額持倉與 Binance 現貨價格，不會查詢鏈上持倉或執行交易。若實際持倉改變，請先更新餘額。

## Cardano 已取消每日鎖

在「資產」頁按「更新持倉餘額」，或「帳戶」頁按「更新資產」，每次都會重新嘗試查詢 Cardano。失敗後也能再次更新，不必等一天。首頁「更新價格」只查價格，兩者已分開標示。

API 本身的 HTTP 429／Retry-After 限流仍會保留，查詢錯誤時保留舊資料與錯誤原因。單次更新可能需要多個 API 請求。歷史圖表的每日價格快取與 Binance 交易對的 24 小時快取不受這次改動影響。
