# v0.1.2 Cardano NIGHT Spot price

Cardano Midnight NIGHT holdings previously had a zero/missing quote because their verified native-asset identity was absent from the price allowlist. Match the full policy ID plus hex asset name to Binance NIGHTUSDT Spot. Hex case is normalized for Cardano; TRON Base58 case remains significant. Token ticker/name alone never selects a price.

- Asset unit: `0691b2fecca1ac4f53cb6dfb00b7013e561d1f34403b957cbb5af1fa4e49474854`.
- Policy ID: `0691b2fecca1ac4f53cb6dfb00b7013e561d1f34403b957cbb5af1fa`.
- Hex asset name: `4e49474854` (NIGHT).
- Identity references: [Midnight NIGHT](https://midnight.network/night) and [Cardano Foundation token registry](https://github.com/cardano-foundation/cardano-token-registry/blob/master/mappings/0691b2fecca1ac4f53cb6dfb00b7013e561d1f34403b957cbb5af1fa4e49474854.json).
- Spot reference: [Binance NIGHT/USDT](https://www.binance.com/en/trade/NIGHT_USDT).

Existing cached NIGHT holdings receive a live quote on portfolio refresh, including during the Cardano balance cooldown. This patch adds no chain request, provider, forced holdings refresh or storage migration. Cardano still allows at most one holdings synchronization attempt per account per 24 hours. Unredeemed/locked allocations that are not wallet holdings remain outside balance discovery.

The regression test covers recovery from a missing quote, uppercase hex, deduplicated NIGHTUSDT requests and rejection of a different policy, different asset name or different chain with the same NIGHT ticker.
