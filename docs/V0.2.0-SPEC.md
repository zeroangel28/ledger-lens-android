# Ledger Lens 下一版規格

狀態：v0.2.0 已實作並通過本機與模擬器測試；實體 Flex USB／藍牙交易仍待驗證。

## 報價與持倉更新

市場快取存放交易對、是否可進行 Spot 交易及檢查時間。已確認結果在 24 小時內直接使用；首次遇到尚無快取的持倉交易對時檢查並建立快取。未知代幣仍必須先建立可信的鏈上識別碼對照，不能僅憑名稱或 ticker 取得其他資產價格。

平常報價使用 Binance Spot 批次 ticker，只請求目前持有且已確認可報價的交易對；相同資產跨帳戶合併請求。每 30 秒的工作只更新價格，不觸發持倉掃描。手動價格刷新不受持倉更新耗時阻擋。避免重疊的請求；離開前景停止定時報價，回到前景再恢復。

手動更新價格可立即取得最新報價，但不強制重新下載未到期的市場資料。網路錯誤保留舊價並標示時間／過期狀態；確認沒有市場或沒有可信代幣識別對照時，維持零估值與無報價標示。

Cardano 交易準備及成功後更新，是平常 24 小時持倉限制的明確例外。一次更新可能包含多個 HTTP 請求，例如地址、UTXO、協議參數；不是承諾只耗一次 API request。交易状态查詢與完整持倉掃描分開，採受限頻率，避免每次查狀態都重掃餘額。

## 接收頁

選擇帳戶與資產，清楚顯示鏈／主網、完整地址、QR Code、複製及分享。USDT 與 NIGHT 同時顯示所屬鏈，避免將同名資產的不同網路混淆。既有地址可以離線顯示；Ledger 核對按鈕在連線後執行相應鏈的設備顯示與本機比對。

沿用目前 Material 3、海軍藍／薄荷綠、繁中／簡中／英文、深淺色及既有無障礙設定。地址可完整查看，不因縮寫而影響核對。

## 傳送頁與交易狀態

1. 選擇來源帳戶及支援的資產。
2. 貼上或掃描收款地址，輸入精確幣數或選擇最大可傳送。先檢查地址網路、格式、數量與小數位。
3. 取得最新交易資料並自動估算費用。BTC／Cardano 使用最新可花費 UTXO；ETH 使用最新 nonce／gas；TRON 使用最新區塊參照、有效期與資源／費用資料。
4. 手機確認頁顯示來源帳戶、鏈、完整收款地址、資產、數量、費用與總支出。USDT、NIGHT 額外列出所需原生幣；NIGHT 輸出所需最低 ADA 與網路費分列。
5. 由使用者確認手機內容，連接／使用 Ledger 對應鏈 App，在 Ledger 實體核對並批准簽名。
6. 本機核對交易內容與返回的簽名，組裝已簽交易後自動廣播。費用或交易內容需要改變時，必須重新建立並重新確認，不能沿用已批准的其他內容。
7. 保存交易 ID 與狀態。廣播被接受顯示等待確認；首次鏈上確認成功後顯示已確認並更新餘額一次。

最大可傳送依即時餘額與預留費用計算；不能只取昨日顯示餘額。Cardano 找零保留被選取 UTXO 中其他資產及其必要 ADA。所有金額以整數最小單位／精確 decimal 處理，不使用浮點數計算交易金額。

等待 Ledger、拒絕、斷線、過期、餘額不足、費用不足、廣播失敗及鏈上執行失敗均有明確狀態。網路逾時導致廣播結果未知時，先按已知交易 ID 查狀態，不自動建立另一筆交易。簽名／廣播按鈕防重複點擊，重開 App 可恢復待確認交易狀態，不自動重簽。

## 實作與驗證邊界

報價快取、前景更新、接收頁與交易流程均納入本次範圍。現有唯讀 APDU 政策需要新增受限的交易簽名通道，不能直接移除全域命令驗證。

驗證包含：快取期限与重啟保存、批次報價與部分失敗、前景／背景切換、手動／定時互斥、地址網路與小數位、選幣／找零／費用、官方簽名向量與返回簽名核對、設備拒絕／斷線／過期、廣播結果未知的處理、待確認狀態恢复、Cardano 交易前後更新與每日限制。

實際 Ledger Flex 的各鏈與兩種傳輸仍需設備驗證。主網交易只會由使用者指定具體收款地址與金額並完成 App／Ledger 確認後送出；開發驗證不自動使用使用者主網資產試轉。
