# 資產歷史估值圖表

v0.4.0，2026-10-09。

開啟「資產」頁，總資產卡片下方會出現「資產歷史估值」。預設一個月，可切換一星期、三個月與半年。按圖表或拖曳日期滑桿可查看指定日期，也能按前一天／後一天，或「查看每日資料」逐日閱讀。深淺色與繁體中文、簡體中文、英文均支援；隱私模式會隱藏曲線、數值與資料表。

計算方式是「目前持倉的幣數 × 當時價格」，不是當時實際持有多少幣，也不是投資損益。例如現在持有 2 BTC，每個歷史日期都以 2 BTC 計算，即使當時還沒有存入。隱藏資產也會計算；餘額未知者不納入，畫面會提醒估值可能不完整。

過去日期採 Binance 現貨的 UTC 每日收盤價，今天使用 90 秒內的有效現貨報價，USDT 的單位價值固定為 1。圖表日期標示 UTC，可能和手機當地日期不同。月份以日曆月份計算；一星期是七天前至今天，含兩端日期。

依你的指定，未上市日期、找不到歷史價格、無法可信對應 Binance 交易對的幣，以及今天沒有有效報價的項目，都以 0 計算。每個日期會顯示有幾個持倉項目以 0 計算；缺漏可能造成曲線跳動。起點總值為 0 時不顯示變化百分比，避免誤導。

歷史價格一次取得最多半年，每個交易對每 UTC 日快取一次，切換期間不重查。多帳戶持有同一種幣只查一次交易對；圖表不增加 Cardano 或其他鏈的持倉查詢。網路錯誤會保留已取得的歷史資料、標示錯誤，沒有資料的日期才以 0 計算。錯誤後至少等候五分鐘或 API 指定的更長時間才重查，重試按鈕也遵守這個間隔。

測試建議：

1. 保留既有 App 資料，覆蓋安裝同簽章 v0.4.0，完成一次正常持倉與報價更新。
2. 檢查預設選到「一個月」，四個期間均可切換；一星期應包含七天前到今天的八個日期。
3. 用日期按鈕與資料表比較同一天的估值。USDT 持倉在所有日期的貢獻應固定；其他幣使用該 UTC 日收盤價。
4. 查看較新上市幣種的上市前日期，確認該幣貢獻為 0 且畫面標示價格缺漏。此時不能把整張圖的區間變化當成真實投資報酬。
5. 隱藏資產列後，圖表總值應不變；開啟隱私模式後，圖表與每日資料表應隱藏。
6. 已載入後切換期間，應立即使用快取。離線重新開啟可使用保存的歷史價格；若缺少新一天的資料或今日有效報價，應出現錯誤／缺漏，而非假裝有完整報價。
